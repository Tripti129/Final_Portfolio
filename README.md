# Tripti Mittal: Developer Portfolio

My personal portfolio: a single-page site that shows my projects, internships, hackathon journey, certifications and coding profile.

## Sections

- **Hero**: intro, typing animation, resume download and social links
- **About**: bio, quick stats and education timeline
- **Skills**: languages, frontend, backend, databases and tools
- **Experience**: internships with certificate links
- **Projects**: featured projects plus smaller ones, linked to GitHub and live demos
- **Hackathon Journey**: a scroll-driven timeline from first hackathon to organizing committee
- **Achievements & Certifications**: certificate gallery with full-size preview
- **Coding Profile**: LeetCode stats (fetched live, with a fallback)
- **Contact**: email, phone and a message form

Interactive touches: a custom cursor, a glow that follows the mouse, spotlight cards, 3D tilt, magnetic buttons and background parallax. They are turned off automatically on touch devices and when "reduce motion" is enabled.

## Tech Stack

React 18 · Vite · Tailwind CSS · Framer Motion · React Icons · react-type-animation. Hosted on Vercel.

## Run Locally

```bash
git clone https://github.com/Tripti129/Final_Portfolio.git
cd Final_Portfolio
npm install
npm run dev
```

Then open http://localhost:5173.

## Updating Content

All content (profile, skills, experience, projects, hackathons and certificates) lives in **`src/data/portfolio.js`**. Edit that file to update the site; no component changes are needed. Certificate images and PDFs go in `public/certificates/`.
